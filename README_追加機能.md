# 追加実装の説明

## 1. 追加した機能
このアプリに、次の機能を追加しました。

- 登録済みデータの編集機能
- CSV形式でのデータ出力
- Excel形式でのデータ出力

## 2. どこを変更したか
### index.php
- 画像アップロード用のフォームを追加しました。
- これにより、名前・メール・画像を一緒に送信できます。

### register.php
- 画像を uploads フォルダへ保存する処理を追加しました。
- 保存した画像のパスを SQLite の image_path に保存します。

### list.php
- 一覧画面に「編集」「CSVで出力」「Excel形式で出力」のリンクを追加しました。
- 各データごとに編集リンクを表示します。

### edit.php
- 既存データを編集するためのページを新規追加しました。
- IDを指定して、名前とメールを更新できます。

### export.php
- SQLite のデータを CSV や Excel 形式でダウンロードできるようにしました。
- CSV は標準的なカンマ区切り形式、Excel は .xls 形式で出力します。

## 3. なぜこの方法にしたか
### 編集機能
- 既存のデータベースに保存された情報を変更できるようにするためです。
- SQL の UPDATE 文を使って、指定した ID のデータを更新します。

### CSV / Excel 出力
- そのまま表計算ソフトで扱いやすくするためです。
- CSV は多くのソフトで読み込め、Excel でもそのままインポートしやすいです。

## 4. 実装手順
1. 既存の SQLite データベースに image_path を追加しました。
2. 画像を uploads フォルダに保存しました。
3. 一覧ページから編集ページへ移動できるようにしました。
4. export.php でデータを整形してダウンロードできるようにしました。
5. それぞれのページを PHP で動作するようにしました。

## 5. 使い方
- 一覧画面で「編集」をクリックするとデータを変更できます。
- 「CSVで出力」をクリックすると CSV ファイルをダウンロードできます。
- 「Excel形式で出力」をクリックすると Excel 形式のファイルをダウンロードできます。

## 6. 補足
- 本番環境では画像保存先を S3 や Cloudinary のような外部ストレージにする方が安全です。
- もし必要なら、次に「削除機能」や「画像削除機能」も追加できます。
